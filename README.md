# 2026_公司旅遊

宇宙科技 2026 員工旅遊活動報名頁。

## 部署

- GitHub Pages 網址：https://star1033.github.io/2026-company-trip/
- Apps Script 專案：[2026_公司旅遊](https://script.google.com/u/0/home/projects/1sLKoGOke6t5GGxvZvYRf7kfcd0mQmjW8BG_UWjK8LAttcPyZjhmiM48d/edit)，程式碼備份於 `Code.gs`。部署為網頁應用程式，執行身分選「我」，存取權選「任何人」。
- 報名資料試算表：[2026_公司旅遊](https://docs.google.com/spreadsheets/d/1wQonfV8wqE6PhIueFChBiwozOp07hxPPH3tkgwZntCc/edit)，第一列為標題列，「電話」欄設為文字格式。
- Web App 網址已設定於 `index.html` 的 `SCRIPT_URL`。
